# 🚀 3D Sorting Visualizer

A modern and interactive **3D Sorting Algorithm Visualizer** built using **HTML, CSS, JavaScript, and Three.js**.  
This project helps students and beginners understand sorting algorithms through real-time visual animations.

---

## 📌 Project Overview

Sorting algorithms are fundamental in computer science, but they can be difficult to understand theoretically.  
This project provides a **visual and interactive approach** to learning sorting techniques using animated 3D cubes.

---

## ✨ Key Features

- 🔢 Supports multiple sorting algorithms:
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Quick Sort
  - Heap Sort

- 🎮 Interactive Controls:
  - Generate random array
  - Manual input of values
  - Adjustable array size
  - Speed control slider

- ⏯️ Execution Options:
  - Start / Pause sorting
  - Step-by-step execution
  - Reset functionality

- 📊 Real-time Statistics:
  - Number of comparisons
  - Number of swaps

- 📜 Algorithm Visualization:
  - Pseudocode display for better understanding

- 🌐 3D Visualization:
  - Built using Three.js
  - Smooth animations and lighting effects

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application  
- **CSS3** – Styling and UI design  
- **JavaScript (ES6)** – Logic and interactivity  
- **Three.js** – 3D rendering and animations
